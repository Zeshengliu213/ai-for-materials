模块导读与教学设计

06 — 无机与晶体材料信息学（Materials Informatics）

前五讲的研究对象都是分子：一个 SMILES 唯一确定一个有边界的原子团。但 \(\text{SrTiO}_3\)、\(\text{TiO}_2\)、\(\text{CsPbI}_3\) 这样的无机晶体没有分子，只有无限重复的周期性点阵；同一个化学式 \(\text{TiO}_2\) 还对应着金红石、锐钛矿、板钛矿三种性质迥异的材料——组成不足以确定材料。

本讲换一套工具：用 pymatgen 表示晶体结构、做对称性分析、构建超胞与点缺陷；打通 CIF / COD / Materials Project 三个数据源；再回答材料信息学最实际的三个问题——合成出来的是什么相（模拟 XRD）、这个化合物能不能存在（热力学凸包）、怎么从几万个候选里挑出值得做的（组成描述符 + 高通量筛选）。

贯穿全讲的一条主线是诚实：一条脏数据能污染上千条形成能；一个随机划分下 \(R^2 = 0.83\) 的模型外推到氟化物只剩 \(0.19\)；一个照搬教科书带隙窗口的筛选漏斗，会把已知的光伏材料全部筛掉。

与前几讲的前后呼应

前序模块埋下的伏笔 本讲在何处兑现与深化
01d：SMILES 唯一描述一个分子 06a 第 1 节：晶体需要“晶格 + 基元 + 空间群”三件套；\(\text{TiO}_2\) 一个化学式对应三种多晶型，CIF 才是晶体世界的 SMILES
02b：随机划分 vs Scaffold Split，随机划分会高估外推能力 06b 第 8 节：材料版的同一教训——留出整类化学后 \(R^2\) 从 0.83 崩到 0.19（氟化物）、0.32（氧化物）
02b / 04a：适用域检查与高斯过程不确定性 \(\sigma(x)\) 06c 习题 8：外推难度取决于留出的化学离训练分布多远（氯化物 0.76 → 0.51，跌幅远小于氟化物）
05a：描述符要有物理意义，SHAP 告诉我们模型在用什么 06b 第 6–7 节：Magpie CBFV 是分子描述符思想在无机材料上的平移；随机森林自己学到“元素带隙与电负性最重要”
05b：PubChem 自由文本要自己写解析器，数据工程是主体 06b 第 4 节：公开 DFT 数据库里一条 S8 = -23.6 eV/atom 会把含硫化合物的形成能带偏约 10 eV/atom；中位数 + 2 eV 容差的稳健参考态
05b：Yalkowsky 方程揭示熔点（晶格能）不在 2D 描述符里 06b 第 4–5 节：晶格稳定性的正式判据——热力学凸包与 \(E_{\text{hull}}\)；以及纯几何的 Goldschmidt 容差因子为何只是窗口型判据（\(r = 0.07\)）
本讲 → 10：DFT 计算量随原子数三次方增长 06a 练习 06a-2：模拟 1% 掺杂需要 625 原子超胞、约 \(2\times10^6\) 倍计算量——这正是第十讲机器学习势函数（MACE）要解决的问题

依赖说明

本讲依赖 pymatgen（已在课程 requirements.txt 中）：

pip install pymatgen

pymatgen 对 numpy / scipy / spglib 的版本比较敏感，建议在干净的虚拟环境或 Colab 中运行。Materials Project 查询需要另装 mp-api 并把密钥放进环境变量 MP_API_KEY——不要把密钥写进 Notebook。
