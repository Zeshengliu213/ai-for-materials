AI for Materials Science

本课程面向零编程基础的材料、化学与物理专业研究生，融合林雪平大学（LiU）AI for Materials Science 宏观教学脉络与 EPFL CH-457 互动实战设计。全程基于 Python、Scikit-Learn、RDKit、Pymatgen 与 PyTorch， 纯 CPU 即可在本地或 Google Colab 流畅运行。

Notebook 互动标记说明

所有实战 Notebook 均采用统一的互动教学标记，建议按“先预测、再运行、后修改”的节奏学习：

📘 讲解
仔细阅读材料/化学物理背景与算法原理
🤔 先猜一猜
运行代码之前先思考程序会输出什么结果
▶️ 运行看看
选中代码格，按 Shift + Enter 执行
✏️ 改一改
修改标有 # ✏️ 的参数后重新运行观察变化
🏋️ 练习
独立编写代码（参考答案位于各章 solutions/）
💡 小贴士
实用的科研工程技巧或后续章节伏笔提示

运行环境配置指南

方式一：Google Colab（零配置推荐）

每份课件页面都有“在 Colab 中打开”按钮，点击即可在浏览器中直接运行，无需本地安装。

方式二：本地 Conda / Python 环境

conda create -n ai4m python=3.10 -y
conda activate ai4m
pip install numpy pandas matplotlib seaborn scikit-learn rdkit pymatgen torch jupyter
