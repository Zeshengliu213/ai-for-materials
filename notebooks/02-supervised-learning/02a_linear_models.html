📘 1.2 留出闭卷测试集与回归三大指标（MAE / RMSE / \(R^2\)）

评估监督学习的第一铁律是绝不能拿训练时见过的数据给模型打分。我们先用 train_test_split 随机留出 20% 分子锁进抽屉当“期末闭卷考题”（测试集 X_test, y_test），只用 80% 训练集拟合模型。

对连续数值预测，最核心的三把尺子是：

  • MAE（平均绝对误差）：\(\frac{1}{n}\sum |y_i - \hat{y}_i|\)，平均偏离多少个 \(\log S\) 单位；
  • RMSE（均方根误差）：\(\sqrt{\frac{1}{n}\sum (y_i - \hat{y}_i)^2}\)，先平方再开方，对预测错得离谱的分子惩罚更重（因为 \(\log S\) 是以 10 为底的对数，\(\text{RMSE} = 1.0\) 意味着摩尔溶解度误差约 \(10^1 = 10\) 倍）；
  • \(R^2\)（决定系数）：\(1 - \frac{\sum (y_i - \hat{y}_i)^2}{\sum (y_i - \bar{y})^2}\)，完美预测为 1.0；如果和“闭着眼全猜训练集平均值 \(\bar{y}\)”一样差，则为 0.0（比瞎猜均值还差甚至会变成负数！）。

2. 最小二乘几何直观与 8 行 NumPy 手写梯度下降

📘 2.1 直线是怎么“找”出来的？

先只看最核心的单个特征——疏水常数 \(x = \text{MolLogP}\)（回忆 01c）。线性模型假设预测值为：

\[\hat{y}_i = w \cdot x_i + b\]

怎样判断哪条直线最好？高斯和勒让德提出了最小二乘法（Ordinary Least Squares, OLS）：计算每个分子真实实验值 \(y_i\) 到直线的竖直残差 \(e_i = \hat{y}_i - y_i\)，求它们的均方误差损失函数：

\[\mathcal{L}(w, b) = \frac{1}{n}\sum_{i=1}^n (w x_i + b - y_i)^2\]

如果我们把所有可能的斜率 \(w\) 和截距 \(b\) 铺成一个平面，损失 \(\mathcal{L}(w, b)\) 就像一只光滑的抛物面大碗。除了用线性代数矩阵求逆直接跳到碗底外，更通用的算法（也是下半学期所有深度神经网络的唯一下山方式）是梯度下降（Gradient Descent）：

  1. 随便站在山坡某处 \((w_0, b_0)\)；
  2. 算出当前脚下最陡的上坡方向（偏导数 / 梯度）：
    \[\frac{\partial \mathcal{L}}{\partial w} = \frac{2}{n}\sum_{i=1}^n (\hat{y}_i - y_i) x_i, \qquad \frac{\partial \mathcal{L}}{\partial b} = \frac{2}{n}\sum_{i=1}^n (\hat{y}_i - y_i)\]
  3. 朝着反方向（下坡）迈出一小步：\(w \leftarrow w - \eta \frac{\partial \mathcal{L}}{\partial w}\)，\(b \leftarrow b - \eta \frac{\partial \mathcal{L}}{\partial b}\)（其中 \(\eta\) 叫学习率 Learning Rate）。

▶️ 运行看看 / ✏️ 改一改：8 行纯 NumPy 亲眼看权重滚入碗底

# 取出标准化后的单特征 MolLogP，方便在统一尺度下观察 (w, b) 损失等高线碗
logp_idx = feature_cols.index("MolLogP")
x_tr_1d = (X_train[:, logp_idx] - X_train[:, logp_idx].mean()) / X_train[:, logp_idx].std()

lr = 0.15          # ✏️ 试试改成 0.02（下山极慢）或 0.98（在碗壁剧烈震荡）！
n_steps = 30       # 迭代步数

# ====== 核心：8 行纯 NumPy 手写梯度下降 ======
w, b = 1.2, 1.5                       # 1. 故意从远离碗底的错误初值出发
history = [(w, b)]
for _ in range(n_steps):
    y_hat = w * x_tr_1d + b           # 2. 前向预测
    err = y_hat - y_train             # 3. 计算残差
    dw = 2.0 * np.mean(err * x_tr_1d) # 4. 对斜率 w 求偏导梯度
    db = 2.0 * np.mean(err)           # 5. 对截距 b 求偏导梯度
    w, b = w - lr * dw, b - lr * db   # 6. 沿负梯度更新参数
    history.append((w, b))
# ============================================

# 对照 scikit-learn 的精确最小二乘解
sk_1d = LinearRegression().fit(x_tr_1d.reshape(-1, 1), y_train)
print(f"手写梯度下降 ({n_steps} 步) -> w = {w:.4f}, b = {b:.4f}")
print(f"scikit-learn 解析解   -> w = {sk_1d.coef_[0]:.4f}, b = {sk_1d.intercept_:.4f}")

3. 多项式特征与偏差–方差权衡（过拟合直观演示）

📘 3.1 线性模型也能拟合曲线？

如果溶解度随 MolLogP 的变化是弯曲的，我们只需用 PolynomialFeatures(degree=d) 把单个特征 \(x\) 扩充成一排幂次特征 \([x, x^2, \dots, x^d]\)，再交给同一个 LinearRegression 去拟合：

\[\hat{y} = w_1 x + w_2 x^2 + \dots + w_d x^d + b\]
因为方程对未知权重 \(w_1, \dots, w_d\) 依然是一次线性的，所以它在数学上仍属于广义线性模型！

但幂次 \(d\) 越高就越好吗？我们从训练集中抽取 40 个分子当小样本训练集，对比 1 阶（直线）、2 阶（抛物线）和 9 阶多项式在训练集与独立验证集上的表现：

4. 17 描述符多元线性回归与“共线性权重反转”破案

📘 4.1 scikit-learn 标准三步曲与对角线图（Parity Plot）

现在我们把全部 17 个 RDKit 描述符一起放进多元线性回归：

\[\hat{y} = w_1 x_1 + w_2 x_2 + \dots + w_{17} x_{17} + b\]

注意 scikit-learn 最优雅的设计——无论后面换成任何监督学习算法，调用永远是统一的三步：实例化 -> fit(X_train, y_train) -> predict(X_test)。为了公平比较不同量纲描述符的权重大小，我们先用只在训练集上 fit 的 StandardScaler 把每列特征标准化为均值 0、标准差 1：

🤔 破案时刻：为什么同为描述分子大小的权重会一正一负剧烈打架？

仔细看右图 (b) 中被标红的几根异常长条（兑现 01c 相关性热图伏笔！）：

  • HeavyAtomCount（重原子数）、MolWt（分子量）、NumValenceElectrons（价电子数）和 LabuteASA（近似表面积）衡量的是同一个物理事实：分子的体积大小（相关系数 \(> 0.96\)）；
  • 甚至 RingCount 严格等于 NumAliphaticRings + NumAromaticRings（精确线性组合）！

当两列特征 \(x_1 \approx x_2\) 高度共线时，对于模型预测来说，\(0.5 x_1 + 0.5 x_2\) 与 -5.5 x_1 + 6.5 x_2 在训练集上算出的总和几乎一模一样！普通最小二乘（OLS）没有任何机制阻止权重膨胀，于是给 HeavyAtomCount 塞了一个巨大的负权重，又给 NumValenceElectrons 和 LabuteASA 塞了巨大的正权重去互相抵消。一旦测试集里出现一个重元素原子（如多碘代分子或金属配合物，价电子数与重原子数比例偏离常规有机分子），这两个巨型正负权重抵消失败，就会像左图 (a) 底部那样预测出 \(\log S = -20\) 的荒唐数值！

5. L2（Ridge）与 L1（Lasso）正则化：给失控权重套上缰绳

📘 5.1 原理与几何直观

解决办法非常优雅——在最小二乘损失后面加一项对大权重的惩罚项（Regularization），参数 \(\alpha > 0\) 控制惩罚力度：

方法 优化目标函数 约束几何形状 对共线性与冗余特征的效果
岭回归 Ridge (\(L_2\)) \(\text{MSE} + \alpha \sum_{j=1}^p w_j^2\) 圆形球面（光滑无尖角） 严厉惩罚极端大权重（平方惩罚），迫使共线特征均匀平摊小权重，权重趋近 0 但不会精确等于 0
套索回归 Lasso (\(L_1\)) \(\text{MSE} + \alpha \sum_{j=1}^p \lvert w_j \rvert\) 菱形多面体（顶点落在坐标轴上） 损失等高线极易先撞上菱形的坐标轴尖角，从而把次要或冗余特征的权重直接归零（\(w_j = 0\)），自带特征筛选！

小结

模型与方法 核心数学直觉 在 AqSolDB 上的启示
普通线性回归（OLS） 最小化竖直残差平方和（梯度下降或矩阵解析解） 快速建立线性基线（RMSE 1.64），但遇到共线描述符时权重正负剧烈对冲，物理不可直接解释
多项式扩展 将 \(x^2, x_i x_j\) 作为新特征喂给线性模型 能捕捉平滑非线性与特征交互，但阶数过高或维度激增时极易引发高方差过拟合
Ridge (\(L_2\)) 与 Lasso (\(L_1\)) 在损失中加入 \(\alpha \sum w_j^2\) 或 \(\alpha \sum |w_j|\) Ridge 稳健抚平共线性（配合二阶特征可将误差显著拉低）；Lasso 自动将冗余特征权重置零
