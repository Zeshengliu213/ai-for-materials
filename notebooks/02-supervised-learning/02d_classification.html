02d · 分类模型与概率：感知机、逻辑回归、评估指标与物理归因

在 02a–02c 中，我们预测的是连续的水溶解度数值 \(\log S\)（回归任务）。但在高通量材料筛查（High-Throughput Screening）中，实验人员往往更关心一个干脆利落的二选一决策：

“这批候选分子里，哪些几乎不溶（\(\log S < -4\)，趁早淘汰），哪些能溶（放行进入合成与测试）？”

当输出变成离散类别标签时，任务就进入了分类（Classification）。本节我们将从 10 行代码手写感知机（Perceptron，“判错就挪直线”）出发，理解为什么加上 Sigmoid 就能变成输出连续概率的逻辑回归（Logistic Regression），掌握全套防坑分类评估指标（混淆矩阵、Precision/Recall、ROC-AUC 与阈值移动），并结合 Yalkowsky 通用溶解度方程剖析有机半导体筛查与金属盐/高熔点晶体的错分真相。

1. 定义“难溶分子筛查”二分类任务与分层抽样

在药物与有机功能分子经验规则中，水溶解度 \(\log S < -4.0\)（摩尔浓度 \(< 10^{-4}\text{ mol/L}\)）通常被划为难溶（Insoluble）警戒线。既然我们的目标是把难溶分子揪出来报警拦截，就将“难溶”定义为正类（Positive = 1），“不难溶/可溶”定义为负类（Negative = 0）：

\[y = \begin{cases} 1 & \text{if } \log S < -4.0 \quad (\text{难溶，重点报警拦截的正类}) \\ 0 & \text{if } \log S \ge -4.0 \quad (\text{可溶，正常放行的负类}) \end{cases}\]

2. 从感知机（Perceptron）到逻辑回归（Logistic Regression）

📘 2.1 感知机（1957）：神经网络的鼻祖与“判错就挪直线”

1957 年 Rosenblatt 提出的感知机（Perceptron）是最古老的线性分类器（也是下半学期神经网络里单个神经元的原型）。它先对特征做线性打分 \(z = \sum_{j=1}^p w_j x_j + b\)，再用一个非黑即白的阶跃函数做硬判决：

\[\hat{y} = \begin{cases} 1 & \text{if } \mathbf{w}^\top \mathbf{x} + b > 0 \\ 0 & \text{otherwise} \end{cases}\]

它的学习规则直白得像实验室带教：挨个看训练分子，猜对了就什么都不动；一旦猜错了，就把分类直线往正确的方向推一把！

\[\mathbf{w} \leftarrow \mathbf{w} + \eta (y_i - \hat{y}_i) \mathbf{x}_i, \qquad b \leftarrow b + \eta (y_i - \hat{y}_i)\]

  • 如果真实难溶（\(y_i=1\)）却漏判成 0（\(y_i - \hat{y}_i = +1\)），就给 \(\mathbf{w}\) 加上 \(\eta \mathbf{x}_i\)，下次遇到类似特征时打分就会变高；
  • 如果真实可溶（\(y_i=0\)）却误判成 1（\(y_i - \hat{y}_i = -1\)），就减去 \(\eta \mathbf{x}_i\)！

📘 2.2 逻辑回归：套上 Sigmoid 变成光滑概率 predict_proba

感知机有两个明显的痛点：

  1. 没有把握度：打分 \(z = +0.001\)（压线险过）和 \(z = +10\)（十拿九稳）都只冷冰冰吐出 1，没法帮实验员排优先级；
  2. 不可微且遇噪声震荡：真实分子总有边界重叠，感知机只要碰到分不开的噪点就会永无休止地来回晃动直线。

**逻辑回归（Logistic Regression）**只做了一个天才改动——把生硬的 0/1 阶跃函数换成光滑 S 形的 Sigmoid 函数：

\[P(y = 1 \mid \mathbf{x}) = \sigma(z) = \frac{1}{1 + e^{-(\mathbf{w}^\top \mathbf{x} + b)}} \in (0, 1)\]

  • 当线性打分 \(z = 0\)（正处分界线上）时，\(\sigma(0) = 0.5\)（五五开）；
  • \(z \gg 0\) 时概率平滑趋近 1.0，\(z \ll 0\) 时平滑趋近 0.0；通过最小化对数交叉熵损失，权重总能稳定收敛到唯一全局最优解！

# 取两个最具物理代表性的特征：MolLogP (疏水性) 与 TPSA (极性表面积)
pair_cols = [feature_cols.index("MolLogP"), feature_cols.index("TPSA")]

# ====== 核心：10 行纯 NumPy 手写感知机 ======
w_p = np.array([-0.5, 0.8])
b_p = 0.0
lr_p = 0.05
for epoch in range(8):
    for xi, yi in zip(X2, y2):
        y_hat = 1 if (np.dot(w_p, xi) + b_p) > 0 else 0
        if yi != y_hat:                       # 判错了才挪直线！
            w_p = w_p + lr_p * (yi - y_hat) * xi
            b_p = b_p + lr_p * (yi - y_hat)

3. 全面评估分类模型：混淆矩阵、ROC-AUC 与实验成本阈值移动

📘 3.1 准确率陷阱与核心分类指标

在测试集中，约 71.5% 的分子本身就是可溶的（0）。如果一个偷懒模型闭着眼把所有分子全判为“可溶”，它的**准确率（Accuracy）**照样高达 71.5%，却漏掉了 100% 的难溶分子！因此分类评估必须拆解 2×2 混淆矩阵：

  • TP（真阳性）：本来难溶，成功拦截；TN（真阴性）：本来可溶，顺利放行；
  • FP（假阳性 / 误报）：本来可溶的好分子，被冤枉淘汰了；
  • FN（假阴性 / 漏报）：本来难溶的坏分子，漏网混进了合成产线！

由此定义：

  • 精确率 Precision \(= \frac{\text{TP}}{\text{TP}+\text{FP}}\)（报出来的难溶分子里，抓准了多少？防冤枉好分子）；
  • 召回率 Recall \(= \frac{\text{TP}}{\text{TP}+\text{FN}}\)（所有真难溶分子里，抓住了多少？防漏放坏分子）；
  • F1 分数：Precision 与 Recall 的调和平均；
  • ROC-AUC：遍历所有概率阈值画出的 ROC 曲线下面积（瞎猜为 0.50，完美区分为 1.00）。

    osc_rows.append({
        "Molecule": name,
        "MolWt": round(Descriptors.MolWt(mol), 1),
        "MolLogP": round(Descriptors.MolLogP(mol), 2),
        "P(insoluble in water)": round(prob, 3),
    })
print(pd.DataFrame(osc_rows).to_string(index=False))

📘 5.2 对照 Yalkowsky 通用溶解度方程破案

物理化学经典的 Yalkowsky 通用溶解度方程（GSE） 完美解释了上面看到的全部现象：

\[\log S \approx 0.5 - \underbrace{\log P}_{\text{液相疏水项}} - \underbrace{0.01 \cdot (T_m - 25)}_{\text{拆毁固体晶格项（熔点 } T_m\text{）}}\]

  1. 为什么置换重要性里 MolLogP 一骑绝尘？ 因为它直接对应方程第一项 \(-\log P\)（溶质进入水相的溶剂化代价）。
  2. 为什么会出现“错分类型 A（离子盐误判）”？ 兑现了 01d 留下的多组分 . 伏笔：像长链季铵盐或有机酸盐，RDKit 按中性原子加和算出的 MolLogP 很高，但带电离子在水中的水合能远超中性分子，导致模型严重误判！
  3. 为什么会出现“错分类型 B（刚性高熔点晶体漏报）”？ 这些中性小分子极性大、MolLogP 很低（甚至为负），模型以为它们极易溶于水；但它们拥有高度对称的平面刚性骨架或多氢键网络，固态晶格能极高、熔点 \(T_m\) 极高，水分子根本拆不开晶格！仅靠单个分子的 2D 拓扑描述符很难算准三维晶体堆积——这正是第 05 模块引入 3D 构象与外部物理特征的原因。
