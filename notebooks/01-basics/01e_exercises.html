下方代码已为你读入 ESOL 数据集 df（包含 name、smiles、logS、MolWt、MolLogP、NumAromaticRings 六列）。 请从 df 中筛选出同时满足以下两个条件的分子：

  1. 芳香环数量 NumAromaticRings == 2；
  2. 实测水溶解度 logS > -2.0。

将筛选结果按 logS 从高到低排序（ascending=False），打印满足条件的分子总数，并显示前 5 行。

  • 预期输出：共 15 个分子，排第一的是 N,N-dimethyl-4-(4-pyridinyl)aniline 或 quinoxaline 等高水溶性双芳环分子（logS 最高为 -0.80）。
In [6] · Python
import pandas as pd
from pathlib import Path
from rdkit import Chem
from rdkit.Chem import Descriptors

for p in [Path("data/esol.csv"), Path("../01 - Basics/data/esol.csv")]:
    if p.exists():
        df = pd.read_csv(p)
        break

df = df.rename(columns={
    "Compound ID": "name",
    "measured log solubility in mols per litre": "logS",
})[["name", "smiles", "logS"]].copy()
mols = df["smiles"].apply(Chem.MolFromSmiles)
df["MolWt"] = [Descriptors.MolWt(m) for m in mols]
df["MolLogP"] = [Descriptors.MolLogP(m) for m in mols]
df["NumAromaticRings"] = [Descriptors.NumAromaticRings(m) for m in mols]
