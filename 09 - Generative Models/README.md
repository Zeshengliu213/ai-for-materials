## 和 ai4chem 的区别

- **换数据集：ZINC（类药分子）→ CEP（有机光伏候选分子）**。理由有两个：CEP 分子正是这门课的主题（噻吩、呋喃、硒吩、苯并噻二唑、咔唑、硅杂环戊二烯等有机半导体构筑单元），而且结构同质、词表只有 20 个 token，CPU 上几分钟就能训练出像样的模型。数据来自 [HIPS/neural-fingerprint](https://github.com/HIPS/neural-fingerprint)（MIT 许可）。
- **代码全部自己搭**。原课程的 RNN 部分明确说"不展示底层模型代码"，只加载预训练模型采样；这里从正则分词器开始，一步步搭出 `Embedding + LSTM + Linear`，并实现采样循环。VAE 部分原课程用的是别人的实现且"没有练习"，这里自己写并配了练习。
- **不依赖 `dl-chem-101`、`molplotly`、`dash`、`h5py`**。原课程需要 clone 仓库、`pip install -e .`、重启内核；这里只要 `rdkit + torch + selfies`。
- **加了原课程没有的内容**：bigram 基线（证明长程约束必须靠记忆）、温度扫描、SELFIES 鲁棒性实验、先验空洞的定量诊断、slerp、定向生成的完整流程、模型欺骗的现场演示、SA score。
- **09b 用微调代替强化学习**。原课程把 REINVENT 放在下一周且需要额外安装；微调（迁移学习）概念更简单、训练更稳定，一分钟就能跑完，而且同样展示了"把生成模型推向目标性质"的核心思想。
- 讲解用中文，图上的文字用英文。标记和前几部分一致：📘 🤔 ▶️ ✏️ 🏋️ 💡。

## 主要结果

- **08a**：词表 20 种 token（加 3 个特殊符共 23）。bigram 基线有效率仅 **0.3%**；预训练 20 轮的 LSTM 在 T=1.0 下有效率 **0.92–0.97**（随运行波动）、唯一性 1.00、新颖性 0.98，降温到 T=0.5 有效率接近 1.00。无效的 SMILES 里语法错和化学错（多数是不能 kekulize 的"芳香环"）各占一半。生成分子的重原子数、芳香环数、MolLogP、TPSA 分布和 CEP 训练数据基本重合，各构筑单元出现频率也几乎一致。温度从 0.5 升到 1.5，有效率单调下降。
- **09a**：SELFIES 字母表 24 个 token。随机改一个字符后仍然有效：SMILES **18.5%** vs SELFIES **100%**。VAE（128 维潜空间，β=0.05，40 轮）重构有效率 0.99、完全还原 **0.179**。先验采样 valid 0.90 / unique 0.997 / novel 1.00，**但**平均芳香环数只有 **0.41**（训练数据 5.73），sp³ 碳比例 0.24（训练数据 0.02）——三个标准指标全优，分子却完全不像训练数据。诊断：编码的 μ 每维标准差仅 0.55、到原点距离中位数 8.5，而先验样本在 11.3。直线插值的中点 ‖z‖ 塌到约 6，同样落在空腔里。在真实分子附近加噪声（σ=0.3）可得到 93% 的新分子且芳香环数仍有约 4。
- **09b**：随机森林代理模型（Morgan 指纹）测试 R² ≈ 0.74、RMSE ≈ 1.3%。用 PCE 最高的 10% 微调 4 轮后，生成分子的平均预测 PCE 从 3.90% 升到 5.80%，**噻二唑**（苯并噻二唑类受体单元）的出现频率从 0.26 升到 0.67（CEP 中 PCE 最高的 10% 是 0.87）——模型"重新发现"了有机光伏领域的经典设计规则。
- **09b 的探针实验**（最重要的一课）：代理模型给**一个水分子**预测出 1.20% 的 PCE，而且 200 棵树的分歧（0.46%）比测试集平均水平（1.07%）还**低**——集成模型的"一致"不等于"正确"。真正有效的警报是相似度：水为 0.000、烷烃 0.03，而训练分子彼此之间的中位数约 0.49。此外苯并噻二唑 ×6（54 个重原子）和 ×12（108 个，训练数据最多 35 个）得到**完全相同**的预测值 6.12%，因为二值 Morgan 指纹已经饱和——模型根本看不见分子变长了。

> 以上数字来自一次具体运行。生成模型对随机种子敏感，重跑会有波动，但趋势稳定。

## 运行环境

- 本地：Python ≥ 3.10，需要 `numpy pandas matplotlib scikit-learn rdkit torch`；09a 还需要 `selfies`
- Colab：PyTorch 已预装；每个 notebook 第一格会按需安装 `rdkit` / `selfies`
- 全部在 CPU 上运行，不需要 GPU
- 数据：本地读 `data/`；Colab 上找不到文件会弹出上传按钮（08a 和 09b 需要同时上传 `cep.csv` 和 `cep_rnn.pt`）
- 运行时间（16 核 CPU）：08a 约 6 分钟（训练 3 轮 + 多次采样），09a 约 6 分钟（VAE 40 轮），09b 约 4 分钟（随机森林 + 微调 + 爬山），参考答案约 12 分钟
